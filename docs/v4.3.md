# V4.3 使用说明

1. 好习惯新增每天、指定星期、每周目标三种频率。指定星期以外免打卡、免扣分；每周目标按北京时间周一至周日统计，周结束后按缺少次数乘未完成扣分值补扣。一天最多打卡一次，每次完成仍获得配置的加分。新建或停用造成的不完整周，目标最多取该周实际启用天数，避免不可能完成的目标。
2. 自定义奖励兑换时产生奖励券，保存在兑换流水中，记录当时名称、说明、价格。兑换人查看待兑现状态，对方可以二次确认已兑现；兑现不会重复扣分。LoveDiary 继续即时解锁，无需人工兑现。
3. 新增手动加扣分流水支持原操作者二次确认撤销。原记录保留，新增反向流水；只允许撤销一次。撤销加分时对方余额须足够，防止负余额。习惯、日记解锁、奖励兑换不进入手动撤销流程。旧版未标记为可撤销的历史流水保留展示。
4. 普通加扣分固定操作当前视角的对方，确认页不再选择归属人。奖励兑换仍消耗自己的积分，自己的习惯仍由打卡自动结算。
5. 好习惯页新增本周、上周看板，按周一至周日展示双方习惯每天的完成、未完成、待完成或休息状态和汇总。窄屏表格支持横向滑动。旧版未存启停历史的习惯，休息状态只能按现有资料展示；已有历史打卡仍显示。

已保留 V4 数据格式的向后读取；双方应升级同一版本后使用。视角切换仍用于黑盒测试，不提供服务端身份认证。运行 npm test 和 npm run build 完成验证及构建。
