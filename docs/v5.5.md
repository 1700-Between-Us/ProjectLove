# V5.5 首页相伴天数绑定修复

首页双城横幅的“相伴 N 天”只使用“在一起的日子”。移除对“在一起、相恋、相识”的宽泛名称匹配，避免其他纪念日新增或保存后排到前面而改变计时。

旧数据按完整名称“在一起的日子”（忽略首尾空格）兼容识别。保存这条记录时写入 `isRelationshipStart: true`，后续改名仍保留绑定。编辑界面显示用途说明；已有绑定时禁止新建同名记录来覆盖它。日期修改后天数随之更新，其他纪念日卡片继续使用原有排序。

未设置、删除或日期尚未到来的情况下，不显示相伴天数，也不使用其他纪念日代替。当日为相伴 0 天。现有日期计算口径不变。

版本更新为 0.5.5，应用缓存更新为 V5.5。113 项测试通过，静态构建成功；未推送或部署。
