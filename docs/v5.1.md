# V5.1 共同愿望清单

从桌面导航或手机底部导航进入愿望清单。双方均可添加和编辑；名称必填，说明、预计日期和地点可选，状态为想一起做、已计划、已完成。支持按状态筛选及归档恢复。

## 关联记录

- 地图：在愿望详情中搜索并关联城市，或编辑时选择已有城市。城市中心的虚线星形标记表示想去，实心标记表示已有到访记录；同城坐标相近的现有城市会复用。一个城市可以关联多个愿望，标点弹窗与城市列表都可打开愿望详情。无地点的愿望也可使用。
- 相册：编辑愿望时新建相册，或选择已有相册、原有文字分组。关联使用相册编号和照片编号；修改相册名称或愿望名称不影响已有照片。相册可供多个愿望关联。相册页面有返回愿望入口；从愿望打开相册后上传，上传表单默认选择该相册。原文字分组仍可继续使用；向已关联相册补照片时请选择对应愿望相册。
- 日记：选择已有日记关联，或从愿望详情写一篇新日记，标题默认带入愿望名称。一个愿望可关联双方的多篇日记；未解锁的对方日记仅展示标题、作者、日期和价格，仍须积分兑换。阅读页面提供关联愿望入口。编辑愿望可取消日记关联，不会删除日记。

## 完成与归档

点击完成愿望并确认完成日期，随后回到详情，可继续补充地点、相册和日记。完成日期不能晚于今天。有已关联城市时，完成状态会让该城市显示为已到访。完成愿望不会产生积分或自动解锁日记。

归档保留所有关联；照片、日记和到访记录不会被删除。编辑时选择不关联可解除地点或相册连接。愿望目前每条关联一个主要城市和一个相册，多篇日记。

## 保存

愿望、相册定义和新增愿望城市与积分资料一起存放于私有仓库的 couple-data/points/shared.json，修改沿用 SHA 冲突保护。照片仍是独立文件，新增照片资料包含相册编号。旧资料可直接读取；双方应升级到同一版本。

自动化检查覆盖稳定关联、相册重命名、归档保留内容、保存失败、城市状态以及日记阅读规则。浏览器视觉验收另行进行。
